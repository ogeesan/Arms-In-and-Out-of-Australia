# The Department of Foreign Affairs and Trade (DFAT)

DFAT numbers are derived entirely from ABS numbers.

It has been reported elsewhere that DFAT's number differ wildy from the ABS.
However, the reason for this is that DFAT uses its own classification system for all goods.
ABS uses X, which is suited for Australia, whereas DFAT uses a classification scheme 
DFAT utilises the same information, but also reclassifies items according to a different system.
